# TOML/YAML 资源探针测量 / TOML and YAML Resource Probe Measurements

## 决定 / Decision

本矩阵在 YAML 8 MiB 输入的宽序列上复现了 AST 构建期的高内存分配失败，也观察到 TOML 在完成 AST 解析后才报节点预算错误且 RSS 超过调查触发线。因此后续需要单独设计解析阶段资源防护。本轮按设计范围只记录证据和边界，不改解析器，不宣称风险已修复，也不将本矩阵泛化为安全结论。

This matrix reproduced a high-memory allocation abort while loading an 8 MiB YAML wide sequence and observed TOML exceeding the investigation trigger before returning a node-budget error after AST parsing. A separate design for parser-stage resource protection is warranted. This implementation records evidence and boundaries only; it does not change either parser or claim the risk is fixed or generally proven safe.

## 方法 / Method

108 个矩阵样本各自作为独立进程运行，每组重复三次。命令模板：

    timeout --signal=TERM --kill-after=2s 15s prlimit --as=1073741824 --cpu=10 -- /usr/bin/time -v PROBE FORMAT SHAPE SIZE MAX_NODES MAX_DEPTH MODE

wide 的 load 参数为 MAX_NODES=262144、MAX_DEPTH=64；deep 的 load 参数为 16、8。generate-only 使用相同形状限额参数，但不调用 ConfigSource::load。另在 YAML wide 4194300 上将节点/深度限额降至 16/8，再独立复测三次。

所有记录都包含完整命令、程序 stdout/stderr、/usr/bin/time -v 输出、外部返回码和控制进程计时。汇总中的 RSS 是每个独立进程的绝对最大 RSS；没有用两个独立进程的 RSS 相减来估算 parser 净开销。输入字节数取探针实际输出。SIZE 对 wide 表示序列元素数，对 deep 表示生成深度参数。

## 结果 / Results

- 共 108 个基准样本和 3 个低节点限额诊断复测。所有 generate-only 样本均完成。
- 没有样本触发 15 秒墙钟或 10 秒 CPU 限额；最大控制进程墙钟时间为 3.832 秒。
- 调查触发线为 RSS 512 MiB 或墙钟 5 秒。没有样本超过 5 秒；宽序列最大样本超过 RSS 触发线。
- TOML wide 4194300，输入 8388607 bytes，node/depth limits 262144/64：三次均在 0.871–0.917 秒后返回 SourceLimitExceeded(node count)，最大 RSS 为 640200–640340 KiB。源码先调用 toml::from_str 构建 TomlValue，再进入展平；节点错误来自展平阶段。因此预算拒绝发生时，完整 AST 已经构建。
- YAML wide 4194300，输入 8388608 bytes，node/depth limits 262144/64：三次均输出 generated=complete，随后因为一次 150994944-byte allocation 失败而以信号 6 / 外部码 134 结束；最大 RSS 为 613172–613472 KiB。该探针没有输出 load_elapsed 或结果。
- YAML 同一输入以更低的 node/depth limits 16/8 再测三次，仍以相同分配失败结束，最大 RSS 为 613220–613448 KiB。由源码调用顺序可确认 serde_norway::from_str 必须返回 YAML AST 才会开始 flatten_yaml_value；本次在生成结束后、from_str 返回前失败，所以 node limit 尚未执行。现有探针不能区分 scanner 与 parser/AST 内部具体分配点，故不对两者作更细结论。
- TOML/YAML 最大宽样本的 generate-only RSS 约 82 MiB；load 样本是不同独立进程，不能将差值解释为 parser 净开销。
- wide 524288 的 TOML/YAML load 均三次返回预期 node count 限额错误；deep 8/64 在两种格式中返回预期 nesting depth 错误。更深 TOML/YAML 样本由 parser/scanner 返回语法或深度拒绝。每个结果和 stderr 均见下方原始记录。
